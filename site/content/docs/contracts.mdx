## ABI

`contracts/abi/frozen.ts` is the frozen source: the `Lien` struct, the `LienStatus` and
`RejectReason` enums, and the deployment shape itself, hand-mirrored from the Solidity interfaces
with zero runtime dependencies so the same file vendors unchanged into the CRE workflow's WASM
build. `caplane-sdk` re-exports these same types from that file rather than restating them — see
the [SDK reference](./sdk/lien) for how they're used.

The generated JSON ABI lives alongside it in `contracts/abi/index.ts`, currently covering the
Registry and Inbox interfaces (`registryAbi`, `inboxAbi`). Neither file is reproduced on this page;
both are generated or hand-frozen from `contracts/src`, not from these docs.
